## 它是什么

[BetterGI](https://github.com/babalae/better-genshin-impact) 跑一条龙的流程是：打开界面 → 选配置 → 点开始 → 别关电脑 → 盯着它跑完。

一条龙管家把这件事收成一颗按钮，并且在你去看剧、吃饭、睡觉的时候替你看着：BGI 还在不在、内存有没有爆、画面是不是卡住了、下一个组该跑了吗。

它**不替代 BetterGI**，也不改游戏或 BGI 的任何文件——只是在外面帮你按按钮、记进度、报信。

## 它做什么

| | |
| --- | --- |
| **一键启停** | 点一下启动 BGI 并跑一条龙，再点一下停止。按钮会自己变状态：灰（没配好）→ 绿（可以跑）→ 红（运行中）。 |
| **跑的时候看着** | 每 5 秒一次心跳，检查进程、内存、画面、进度。BGI 半路消失且一条龙没跑完，会等 60 秒冷却后自动拉起来。 |
| **跑完叫你** | 完成、崩溃、卡死、内存告警，可以推到系统通知，也可以推到手机（企业微信 / 飞书 / 钉钉 / Telegram / Bark / 邮件 / Webhook 等）。 |
| **定时** | 每天或指定星期几的某个时刻自动开跑，到点只跑一次，错过不补。 |
| **多组连跑** | 勾选几个配置组，按勾选顺序依次执行，不用守着换配置。 |
| **可换外观** | 深色 / 浅色 / 跟随系统，也可以用调色板或自己的图片当背景。 |

## 界面

主界面一屏装完，从上到下四块，各管一件事：

<p align="center">
  <img src="docs/main_light.png" alt="浅色主题下的主界面" width="820">
</p>

- **上左 · 每天自动跑一条龙**：开关 + 重复日 + 时间。点时间进入编辑页，改完点「返回」。
- **上右 · 启动台**：大按钮和它的状态。没配好时点它会被抖一下并展开缺失项；旁边是「仅启动 BGI」的副按钮。
- **中间 · 守护条**：一行摘要（守护开没开、四项正不正常），点整条展开明细。
- **下部 · 执行配置组 / 一条龙配置**：勾选要跑的组（① ② ③ 就是执行顺序），以及 BGI 路径和配置名。

## 守护模式

<p align="center">
  <img src="docs/guardian_dark.png" alt="守护条展开：四项监测、今日组、最近事件、心电波形" width="820">
</p>

展开后是四路监测，各管一摊、互不影响：

| 监测 | 看什么 | 异常时 |
| --- | --- | --- |
| 崩溃自动重启 | BGI 进程是否消失、一条龙是否仍在进行 | 冷却 60 秒后自动重启一条龙 |
| 内存监控 | 系统占用 / BGI 工作集 | 只提醒，不动进程 |
| 画面冻结检测 | 定时截图与上一张的灰度差异 | 只提醒，保留截图 |
| 进度识别 | BGI Webhook 事件，没有则退回日志解析 | 更新组进度、判断跑完没 |

底部那条心电不是摆设：波形在动就说明心跳还在跑，颜色跟状态走（空闲灰、运行绿、异常红）。双击它可以把五种状态循环演示一遍。

**三条不做的事**（宁可漏报，也不误杀）：画面冻结不重启、原神退出不重启、只有"BGI 消失 + 一条龙进行中"同时成立才考虑重启。

## 定时

<p align="center">
  <img src="docs/time_picker_dark.png" alt="定时编辑页：24 小时双圈圆盘" width="820">
</p>

- 圆盘：外圈 1–12、内圈 13–23 与 0，点选或按住拖动；选完小时自动进分钟盘。
- 键盘：直接敲 `0830`，适合精确输入。
- 重复日：每天或星期组合；当天到点只触发一次。
- 改完点「返回」会立刻回到概览，卡片高度同帧校正，不会出现半秒错位。

## 外观

四档：深色 / 浅色 / 跟随系统 / 自定义。前三个是预设；自定义可以做两件事：

<p align="center">
  <img src="docs/theme_editor.png" alt="自定义主题编辑器：左侧实时预览、右侧参数、底部对比度读数" width="720">
</p>

- **调色板取色**：18 个预设色 + 系统取色器。
- **图片背景**：选一张本地图，调遮罩强度（0–90%）。

编辑器左边是实时预览，改一个参数全应用立刻跟着变；底部会实时算正文对比度（`15.4:1 · AAA` 这种）。「恢复默认主题」一键回到跟随系统，「取消」不写入配置。

自定义背景能保证看得清，靠的是三层：背景图 → 半透明遮罩 → 卡片，**文字永远落在卡片上**；卡片的亮度按当前方案锚定（深色方案向 `#16191F` 混 93%，浅色方案向白混 90%），所以换个再艳的背景也不会把字糊掉。

## 快速开始

**前提**：Windows 10/11 x64、已装 BetterGI 本体、有管理员权限（结束 BGI 进程需要）。

两个版本功能一样，区别只在「运行时」放在哪：

| | runtime-dependent（需 .NET 8 运行时） | portable（免安装便携版） |
| --- | --- | --- |
| 压缩包 | `Dragon-Butler-v1.2-win-x64-runtime-dependent.zip` | `Dragon-Butler-v1.2-win-x64-portable.zip` |
| 大小 | 约 0.22 MB | 约 62.7 MB |
| 要求 | 已装 [.NET 8 桌面运行时](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0) | 无，自带运行时 |
| 适用 | 机器上已有 .NET 8，想下最小包 | 不确定有没有 .NET 8、要换电脑或放 U 盘 |

> 文件名规则是 `Dragon-Butler-v<版本>-<平台>-<变体>`：`v1.2` 是当前版本（与日志里 `启动：Dragon Butler v1.2.0` 一致），`win-x64` 是平台，`runtime-dependent` / `portable` 是变体。
> 解压出来的目录名固定为 `Dragon-Butler-win-x64-runtime-dependent\` 或 `Dragon-Butler-win-x64-portable\`，**不带版本**——升级时直接覆盖原目录，`config\` 里的设置不会丢。

> **两个版本都不用"安装"**：没有安装向导、不写注册表、不注册服务，解压后双击 exe 就能用，删掉文件夹就是卸载。
> 区别只在于 exe 里有没有打包 .NET 运行时——没打包的那个，需要电脑上已经装过一次 .NET 8 桌面运行时（微软免费，装一次以后所有 .NET 8 程序都能用）；已经装过的话，两个版本用起来没有任何区别。

```
1. 解压 → 双击 Dragon Butler.exe（UAC 点「是」）
2. 「一条龙配置」→ 更改 → 选中 BetterGI.exe
3. 点「▶ 立刻启动一条龙」
```

跑起来之后建议再补三步：

1. 想挂机 → 打开定时并设好时间，顺手开开机自启；
2. 想收消息 → 「通知」卡选一个渠道填地址，点「测试」；
3. 想让进度更准 → BGI 设置里把 Webhook 填成 `http://127.0.0.1:18235/webhook`（界面有复制按钮）。不填也能用，会退回日志解析。

## 数据在哪

全部在 exe 旁边，删掉文件夹就是卸载（开过自启的先去「系统」里关掉）：

```
Dragon Butler.exe
├─ config\settings.json        # 所有设置，可手改
├─ config\group_archive.json   # 今天跑了哪些组
├─ sounds\                     # 自动生成的 6 个按键音
└─ 全部日志\                    # 运行日志（出问题先看这里）
```

不写注册表（除开机自启那一个值）、不写 `%APPDATA%`，整个文件夹可以拷走接着用。

## 常见问题

<details>
<summary><b>提示「找不到 BetterGI」</b></summary>
路径要选到 <code>BetterGI.exe</code> 本身，不是它所在的文件夹。
</details>

<details>
<summary><b>需 .NET 8 运行时版双击没反应 / 报缺框架</b></summary>
没装 .NET 8 桌面运行时。装上，或换免安装便携版。
</details>

<details>
<summary><b>自定义背景后字看不清</b></summary>
遮罩拉到 60–75%，文字配色切到与背景相反的方向。编辑器底部的对比度 ≥4.5:1 就达标，≥7:1 是 AAA。
</details>

<details>
<summary><b>守护会误杀我的游戏 / 别的 BGI 吗</b></summary>
不会。所有进程查找和结束都按当前 Windows 会话过滤，而且冻结、原神退出这两类情况只提醒不重启。
</details>

<details>
<summary><b>托盘还有图标，再双击提示「已在运行」</b></summary>
程序是单实例的。托盘右键可以「打开主界面」或「退出」。
</details>

<details>
<summary><b>心电波形不动了</b></summary>
窗口最小化或被完全遮挡时会暂停渲染省 CPU，切回来继续。长时间不动就看「全部日志」里守护是否还在跑。
</details>

## 版本号规则

用两段式 `主版本.次版本`：

- **次版本 +1**（v1.1 → v1.2）：每次可交付的改动，包括新功能、体验优化、修 bug。
- **主版本 +1**（v1.x → v2.0）：只在核心能力或大改动时进位，比如换了运行方式、加了整套新模块。
- 不设第三位（没有 v1.1.1）——单机桌面工具不做"只修 bug 的补丁包"，修复直接进下一个次版本。
- `v0.x` 是开发期，`v1.0` 是第一个可以给别人用的版本；现在在 `v1.2`。

完整历史见 [BUILD_REPORT.md](BUILD_REPORT.md)。

## 已知边界

- 只支持 Windows x64 + .NET 8；没有 macOS / Linux 版本。
- 不带自动更新，新版本要手动替换 exe（配置和日志会保留）。
- 进度识别依赖 BGI 的 Webhook 或日志格式，BGI 大改版后可能需要适配。
- 画面冻结检测需要游戏窗口可见，最小化到托盘时这一路会跳过。
- 自定义图片背景的亮度取整图平均色，极端构图（半黑半白）可能判不准，用「文字配色」手动锁定。
