## 为什么搬走而不是删掉

它们记录的当时怎么验收，事后追查「这条规则为什么是这样」还有用；但内容已过时，放在根目录会让每次进仓库都要先扫过它们。搬进来之后，根目录的 `*_REPORT.md` 只剩按版本命名的现行报告（`V141_REPORT.md` 起）。
