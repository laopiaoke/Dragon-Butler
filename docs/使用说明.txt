一条龙管家 Dragon Butler · 使用说明
================================================

一、这是什么
------------------------------------------------
BetterGI（原神桌面自动化）的「启停管家 + 守护工具」。
一颗大按钮启动 / 停止一条龙；离开电脑时守护模式持续盯着，
BGI 崩了自动拉起、跑完或卡死会推送通知，配置组进度一眼可见。

全程不需要打开 BetterGI 界面，也不用改 BGI 里的任何推送设置。

二、两个版本怎么选
------------------------------------------------
两个版本都是「绿色软件」：不用安装、不写注册表、不建服务，
解压后双击 exe 就能用，删掉文件夹就是卸载。

唯一的区别是「运行时」放在哪。下载时按压缩包名区分：

  Dragon-Butler-v1.2-win-x64-runtime-dependent.zip   ← 需 .NET 8 运行时版
  Dragon-Butler-v1.2-win-x64-portable.zip            ← 免安装便携版

（名字规则：Dragon-Butler-v版本-平台-变体）

· 需 .NET 8 运行时版（exe 约 0.46 MB）
  运行时不在包里，要用电脑上已装的「.NET 8 桌面运行时」
  （Windows Desktop Runtime 8.0 x64，微软免费，装一次即可）。
  - 已经装了 → 双击就能跑，和便携版没有任何区别；
  - 没装 → 双击会弹出「需要 .NET」的提示并给下载地址，装完再双击即可。

· 免安装便携版（单文件约 155 MB）
  运行时已经打包进 exe 里，任何 Windows 10/11 x64 双击就能跑，
  不需要提前装任何东西。放 U 盘、换电脑、重装系统都能直接用。

两个版本功能完全一样，只是「要不要先补一个运行时」的差别。

三、第一次使用
------------------------------------------------
1. 双击 Dragon Butler.exe。
   程序需要读取游戏进程和结束 BGI 进程，因此会申请管理员权限（UAC 点「是」）。

2. 在「一条龙配置」卡片点【更改】，选中 BetterGI.exe。
   路径要选到 exe 文件本身，例如 D:\BetterGI\BetterGI.exe。

3. 选择要跑的内容：
   · 只填「一条龙配置名」→ 跑该配置的一条龙；
   · 在「执行配置组」里勾选若干个组 → 按勾选顺序依次执行（1、2、3 就是顺序）；
   · 两者都填时，以勾选的配置组为准。

4. 点【立刻启动一条龙】即可。
   运行时按钮变红，再点一次就是停止（会先优雅关闭，兜底再强制结束）。

四、几个常用的功能
------------------------------------------------
· 定时自动跑：打开定时卡开关，点时间可改成任意时刻，支持「每周几」重复。
  到点自动启动一条龙，电脑不在身边也能照常跑。

· 守护模式：默认开启。5 秒一次心跳，盯着进程、内存、画面冻结、任务进度。
  BGI 意外消失且一条龙还在进行中时，会在 60 秒冷却后自动重启。

· 消息通知：「通知」卡片可选系统通知 / 企业微信 / 飞书 / 钉钉 / Telegram /
  Bark / 邮件 / Webhook 等渠道，跑完或出问题推到手机。

· 主题与音效：右上角可切「深色 / 浅色 / 跟随系统 / 自定义」。
  自定义主题支持调色板取色或选一张图片当背景，可调遮罩强度，左侧实时预览；
  「恢复默认主题」一键还原。按键音效默认关闭（静音），想听声音到「系统」卡打开。

五、文件都在哪
------------------------------------------------
所有数据都放在 exe 旁边，不写注册表、不写 %APPDATA%：

  config\settings.json   你的全部设置（删掉即恢复默认）
  config\group_archive.json  配置组当天的执行记录
  sounds\                程序自动生成的按键音效
  全部日志\              运行日志，出问题先看这里

整个文件夹可以直接拷走，换台电脑接着用。

六、常见问题
------------------------------------------------
Q：提示「找不到 BetterGI」？
A：路径要选到 BetterGI.exe 本身，不是它所在的文件夹。

Q：启动后没反应 / 秒退？
A：先看「全部日志」里当天的日志；「需 .NET 8 运行时」版请确认已装好 .NET 8 桌面运行时。

Q：托盘里还有图标，再双击 exe 提示「已在运行」？
A：程序是单实例的，从右下角托盘图标右键可以唤出主界面或退出。

Q：会误杀游戏或别的 BGI 吗？
A：所有进程操作都按「当前 Windows 会话」过滤，不会动别的用户会话里的进程。

Q：怎么卸载？
A：退出程序后直接删掉整个文件夹即可（若开过开机自启，先在设置里关掉）。
