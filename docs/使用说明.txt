一条龙管家 Dragon Butler · 使用说明
================================================

一、这是什么
------------------------------------------------
一站式游戏管家：把你在用的自动化工具（BetterGI、三月七助手、ok-ww，以及任何 exe）
排成一条队列，按顺序启动、盯着跑完、再收尾。
勾好今晚要跑的工具点一次，跑完给你一条汇总消息；需要的话顺手帮你睡眠或关机。

离开电脑也不怕：守护模式持续盯着，BGI 崩了自动拉起、跑完或卡死会推送通知，
挂机护航替你顶住系统的睡眠、重启与屏保。

全程不需要打开 BetterGI 界面，也不用改 BGI 里的任何推送设置。

二、两个版本怎么选
------------------------------------------------
两个版本都是「绿色软件」：不用安装、不写注册表、不建服务，
解压后双击 exe 就能用，删掉文件夹就是卸载。

唯一的区别是「运行时」放在哪。下载时按压缩包名区分：

  Dragon-Butler-v1.10-win-x64-runtime-dependent.zip   ← 需 .NET 8 运行时版
  Dragon-Butler-v1.10-win-x64-portable.zip            ← 免安装便携版

（名字规则：Dragon-Butler-v版本-平台-变体）

· 需 .NET 8 运行时版（exe 约 0.56 MB）
  运行时不在包里，要用电脑上已装的「.NET 8 桌面运行时」
  （Windows Desktop Runtime 8.0 x64，微软免费，装一次即可）。
  - 已经装了 → 双击就能跑，和便携版没有任何区别；
  - 没装 → 双击会弹出「需要 .NET」的提示并给下载地址，装完再双击即可。

· 免安装便携版（单文件约 155 MB）
  运行时已经打包进 exe 里，任何 Windows 10/11 x64 双击就能跑，
  不需要提前装任何东西。放 U 盘、换电脑、重装系统都能直接用。

两个版本功能完全一样，只是「要不要先补一个运行时」的差别。

三、第一次使用
------------------------------------------------
1. 双击 Dragon Butler.exe。
   程序需要读取游戏进程和结束 BGI 进程，因此会申请管理员权限（UAC 点「是」）。

2. 展开「工具」卡，给要用的工具指路：
   · 点【浏览】选中 exe（例如 D:\BetterGI\BetterGI.exe，要选到 exe 文件本身）；
   · 或点【自动寻找】让它自己找，命中后点「使用此路径」才生效；
   · 点【测试启动】可以单独试一下这个工具能不能起来。

3. BetterGI 卡里再选要跑的内容：
   · 只填「一条龙配置名」→ 跑该配置的一条龙；
   · 在「执行配置组」里勾选若干个组 → 按勾选顺序依次执行（1、2、3 就是顺序）；
   · 两者都填时，以勾选的配置组为准。

4. 回到上面的「睡前队列」卡，勾上今晚要跑的工具（可拖动排序），
   点【一键开跑】。运行时按钮变红「停止」，再点一次就是停下整个队列
   （先优雅关闭，兜底再强制结束）。只想单独跑一个，用工具卡里的【测试启动】。

四、几个常用的功能
------------------------------------------------
· 定时自动跑：打开定时卡开关，点时间可改成任意时刻，支持「每周几」重复。
  到点自动启动一条龙，电脑不在身边也能照常跑。
  错过会补跑：电脑睡过头、程序没开、上一轮还没跑完，只要还在补跑窗口内就会补上，
  日志里写「补跑（计划 08:00，实际 09:12）」。窗口默认 120 分钟，定时卡上可调或关掉。

· 接着跑：跑了一半被打断（停了、失败了、关机了），不用从第一项重来。
  只要今天已经跑成过至少一项、并且还有没成功的，队列卡会出现「接着跑（今天还剩 N 项）」，
  托盘菜单里也有。它只跑没成功的，跑成过的直接跳过。

· 守护模式：默认开启。5 秒一次心跳，盯着进程、内存、画面冻结、任务进度。
  BGI 意外消失且一条龙还在进行中时，会在 60 秒冷却后自动重启。

· 挂机护航：队列跑起来后自动按住系统——不空闲睡眠、不因更新弹重启、不弹屏保，
  跑完自动把原设置还回去。不需要配置，也不改动你的电源计划。

· 夜间息屏：高级设置里可设「运行 N 分钟后关闭显示器」（默认关）。
  只是关屏，系统仍然保持唤醒，队列照常在后台跑。

· 疑似挂起：进程还活着，但 CPU 和日志连续 3 分钟都没动静，会在队列里标成「疑似挂起」
  并暂停队列、发通知等你处理；勾上「自动终止疑似挂起」则会结束进程并继续下一项。

· 自定义工具：工具卡最下方点「＋ 添加」，填程序路径、进程名、完成方式即可接入任意 exe。
  完成方式三种：
    「进程退出（退出码 0）」适合跑完自己退出的；
    「到达时长」适合不会退出的，跑满 N 分钟算完成并自动结束进程；
    「自定义信号」填日志文本 / 等待文件 / 窗口标题，任意一个命中就算完成（至少填一项）。
  图标会自动从 exe 里取，取不到就用首字母；任何工具都能点「换图标」换成自己的图，可随时还原。

· 按日计划：队列卡右上角「按日计划」打开 7 天 × 各工具的勾选表，
  可以给不同工具分配不同的星期（例如周本放周末）。它只影响定时触发：
  手动点「一键开跑」永远跑当前勾选；某天一个都没勾，到点会跳过并发一条提醒。
  队列里每个工具后面会显示「每天 / 6天」，队列下方写着今天跑哪几项。

· 晨报（默认关）：高级设置里打开后，每天第一次启动时用一句话汇报昨天的情况，
  例如「昨日队列：2 次运行，全部成功，总耗时 3小时12分」。昨天没跑就不播。

· 消息通知：「通知」卡片可选系统通知 / 企业微信 / 飞书 / 钉钉 / Telegram /
  Bark / 邮件 / Webhook 等渠道，跑完或出问题推到手机。
  通知里会写明为什么没跑成——退出码、最后一条错误日志行、悬置或挂起的判据，
  不再只有一句「详情见软件日志」。失败时还会附带现场包的文件夹路径。

· 失败现场包（默认开）：失败 / 悬置 / 挂起的那一刻自动打包一份现场，存进
  「全部日志\incidents\」下按时间命名的文件夹，里面有：
    log.txt    出事前最后 200 行日志
    env.json   版本、系统、失败原因、失败工具的档案、进程列表、脱敏后的全部设置
    screen.png 当时的屏幕（有游戏窗口截游戏区域，没有则全屏）
  推送地址、Token、密码、邮箱这些一律替换成 ***，不会跟着包传出去。
  默认保留最近 10 份，可在设置里关掉或改份数。

· 失败重试：添加/编辑自定义工具时可以填「重试几次、每次等多久、等待是否逐次翻倍」。
  次数不含首次（默认 1 次），等待默认 3 秒，翻倍默认开（3 → 6 → 12 秒，封顶 300 秒）。

· 本机控制 API（默认关）：打开后脚本、快捷方式、AI 助手可以直接指挥它。
    GET  http://127.0.0.1:18235/api/status              查状态（返回 JSON）
    GET  http://127.0.0.1:18235/api/start               开跑整条队列
    GET  http://127.0.0.1:18235/api/stop                停止
    GET  http://127.0.0.1:18235/api/run?tool=bettergi   单跑一个工具
  请求头必须带 X-Butler-Token: <令牌>，令牌在开关打开时自动生成，卡片上可以一键复制。
  开关关着时这些地址一律返回 404——不告诉外面「这里有个接口」。
  例：curl -H "X-Butler-Token: 你的令牌" http://127.0.0.1:18235/api/status

· 手机看进度（默认关）：打开后同一个 Wi-Fi 下的手机浏览器打开卡片上显示的地址，
  就能看当前在跑谁、今天跑成几项、最近一条事件。页面没有任何按钮，只能看不能指挥；
  想看的同时能指挥，用上面的控制 API 自己写。若手机打不开，先给本程序放行防火墙。

· 周报（默认关）：每周第一次打开时汇报近七天——哪天跑了、成功率、总耗时。
  和晨报一样，只在启动时播一次，不启动就等下次。

· 全局热键（默认关）：打开后在「系统」卡里填组合。默认 Ctrl+Alt+R 开跑、Ctrl+Alt+S 停止，
  游戏全屏时也管用。写法要像 Ctrl+Alt+R —— 至少一个修饰键（Ctrl/Alt/Shift/Win）加一个主键；
  写错会退回原来的值并提示。程序退出时组合键自动还回去，不会被永久占用。
  默认关的原因：全局热键会霸占组合键，部分游戏的反作弊也会盯着这类注册。

· 一眼看到进度：跑队列时任务栏图标上会出现进度条，托盘图标悬停显示「第几项 / 共几项」。
  托盘菜单里没有加进度条目——菜单是偶尔点的地方，进度是扫一眼的东西。

· 迷你浮条（默认关）：一条 180×44 的小条，只显示当前在跑谁、还剩几项。
  可以拖动到任意位置并记住；双击回到主界面；右边的 ✕ 是关掉这个功能。

· 现在就到：托盘菜单里点「现在就到」，立刻抓一张当前画面，存进 全部日志\snapshots\
  （保留最近 20 张），并把路径推到通知里。出门在外想知道卡在哪时用得上。
  说明：图片是存本地再推路径，不是直接塞进通知——11 个推送渠道里只有自定义 Webhook
  和 WebSocket 能带附件，其余都是纯文本。

· 挂机日历：主界面队列卡右上角「挂机日历」，把过去一年摊成方格墙——一格一天，
  绿色全部跑成、黄色有失败、红色全没成、灰色没跑。数据全部来自已有的队列记录，
  不额外抓任何东西。

· 跑完说一句话（默认关）：队列结束时用系统语音念一句「一条龙跑完了，N 项全部成功，用时 X」。
  只在成句的地方念，不念通知正文（【】、路径、退出码念出来没法听）。
  精简版 Windows 可能没有语音引擎，那种情况下开关会自动保持关闭并说明原因。

· 命令面板：主界面按 Ctrl+K，出一个搜索框——输入「日历」「令牌」「浮条」直接跳到对应位置，
  也可以直接执行「一键开跑」「停止」「单跑某个工具」。上下键选择、Enter 执行、Esc 关闭。
  只在主界面有焦点时响应；游戏里按 Ctrl+K 不会叫出管家（那是全局热键的活）。

· 依赖编排：队列卡右上角「依赖」按钮，出一张勾选矩阵。
  行是「要跑的」，列是「要先跑成的」——在某行给某列打勾，表示这一项必须等那一项跑成之后才开跑。
  勾完之后整条队会按依赖顺序跑：被依赖的自动提前，同一层保持你原来的顺序。
  某一项的前置没跑成时，可以选「跳过这一项」（默认，后面不依赖它的照常跑）
  或「整队停下」（后面的一律不跑，等你看过再说）。这个选择是整张表共用的。
  如果勾出环（A 等 B、B 又等 A），保存时会直接拦下来并告诉你是哪几项绕住了，不会存进去。
  什么都不勾＝和以前完全一样，一条直线跑下去。

· 配置组切片：队列卡右上角「配置组」按钮。左边选一项，右边勾「它要跑哪几个配置组」。
  用途是让同一条队在不同时段跑不同的组：白天刷日常组、晚上刷活动组，中间不用人来改设置。
  什么都不勾＝沿用主界面上那份全局勾选，行为和以前完全一样（升级上来的老配置就是这种状态）。
  组名是从 BetterGI 的 User\ScriptGroup 目录里扫出来的；在 BGI 里删掉或改名过的组，
  这里会被自动忽略（只写一行日志，不报错）——因为让 BGI 带着一个不存在的组启动会直接失败。

· BetterGI 版本提醒：程序会记住上一次**跑成功**时用的 BetterGI 版本。
  下次开跑前如果发现版本变了，会提醒一句「如果这次跑得不顺，多半是版本变化引起的」。
  它只读本地 BetterGI.exe 的文件版本号，不联网、不下载、也不会替你更新。
  第一次运行只写一行日志不弹通知；读不到版本号时保持沉默，不会因为不知道而乱报。
  同一个版本重新编译（版本尾巴的哈希变了）不算版本变化。

· 收益账本（默认关，在「高级设置」里打开）：
  从 BetterGI 的日志里累计摩拉、狗粮经验、拾取材料，队列结束时在通知里补一句
  「本次约 12.5 万摩拉、甜甜花×12。本月累计 340 万摩拉」。
  它不新增任何采集，只是顺手看一眼本来就要读的日志行。
  解析故意写得保守：只认「摩拉 +125000」这种带明确分隔符的形状，
  「摩拉收益 26-28w」「12.5万摩拉」这类带区间或单位的写法一律不认——
  宁可少算，也不猜。某个脚本根本不打印收益，账本里对应的就是空的。
  账本存在 exe 旁的 config\harvest.json，只保留最近 400 天，删掉只是清空统计。
  没有做「折合多少代肝费」的换算：代肝价格是市场行情会变，把爱好换算成钱该由你自己判断。

· 晨报补跑提示：昨天该跑却没跑成时，晨报会多一句
  「昨天 08:00 的定时没跑成（补跑窗口 120 分钟内没跑起来）」。
  以前这件事是静默的，你第二天只看到「上次执行：两天前」，不知道是没开机还是跑挂了。
  如果昨天本来就不在计划里（没勾那个星期几），它不会说话。

· 主题与音效：右上角可切「深色 / 浅色 / 跟随系统 / 自定义」。
  自定义主题支持调色板取色或选一张图片当背景，可调遮罩强度，左侧实时预览；
  「恢复默认主题」一键还原。按键音效默认关闭（静音），想听声音到「系统」卡打开。

五、文件都在哪
------------------------------------------------
所有数据都放在 exe 旁边，不写注册表、不写 %APPDATA%：

  config\settings.json   你的全部设置（删掉即恢复默认）
  config\group_archive.json  配置组当天的执行记录
  tools\                 每个工具一份档案（内置三个 + 你自己加的），删掉即恢复内置默认
  cache\icons\           从 exe 里提出的图标缓存，删掉会自动重建
  sounds\                程序自动生成的按键音效
  全部日志\              运行日志，出问题先看这里

整个文件夹可以直接拷走，换台电脑接着用。

六、常见问题
------------------------------------------------
Q：提示「找不到 BetterGI」？
A：路径要选到 BetterGI.exe 本身，不是它所在的文件夹。

Q：启动后没反应 / 秒退？
A：先看「全部日志」里当天的日志；「需 .NET 8 运行时」版请确认已装好 .NET 8 桌面运行时。

Q：托盘里还有图标，再双击 exe 提示「已在运行」？
A：程序是单实例的，从右下角托盘图标右键可以唤出主界面或退出。

Q：会误杀游戏或别的 BGI 吗？
A：所有进程操作都按「当前 Windows 会话」过滤，不会动别的用户会话里的进程。

Q：队列停在一项不动，卡片上写着「疑似挂起」？
A：说明进程还活着但 3 分钟内既没吃 CPU 也没写日志。看一眼游戏画面是否卡住，
   处理完点「继续」；不想每次都手动，可以在高级设置里打开「自动终止疑似挂起」。

Q：跑着跑着显示器黑了 / 电脑睡了？
A：只有「夜间息屏」会关显示器，那是正常的（系统仍在跑，动一下鼠标就亮）。
   其他情况不该发生——挂机护航会顶住空闲睡眠，跑完自动还回原设置；
   若确实睡了，到「全部日志」搜「护航」看有没有被别的程序抢回去。

Q：能加自己的工具吗？
A：能。工具卡最下方「＋ 添加」，填路径、进程名、完成方式即可，图标会自动提取。
   完成方式里最灵活的是「自定义信号」：日志文本 / 等待文件 / 窗口标题，填一项就行。

Q：按日计划设了，为什么手动开跑还是全跑？
A：按日计划只约束定时触发，手动「一键开跑」永远按当前勾选跑，方便临时补跑。
   想知道今天跑哪几项，看队列卡下方那行「今天（周五）跑 2 项」。

Q：晨报怎么开，为什么没播？
A：高级设置里打开「晨报」（默认关）。它每天只在第一次启动时播一句，
   昨天没有任何运行记录时不播；改完设置重启一次即可生效。

Q：怎么卸载？
A：退出程序后直接删掉整个文件夹即可（若开过开机自启，先在设置里关掉）。

七、版本
------------------------------------------------
v1.10 · Windows 10/11 x64 · 需要 BetterGI 本体（另装）
