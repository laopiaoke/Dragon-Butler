一条龙管家 Dragon Butler · 使用说明
================================================

一、这是什么
------------------------------------------------
一站式游戏管家：把你在用的自动化工具（BetterGI、三月七助手、ok-ww，以及任何 exe）
排成一条队列，按顺序启动、盯着跑完、再收尾。
勾好今晚要跑的工具点一次，跑完给你一条汇总消息；需要的话顺手帮你睡眠或关机。

离开电脑也不怕：守护模式持续盯着，BGI 崩了自动拉起、跑完或卡死会推送通知，
挂机护航替你顶住系统的睡眠、重启与屏保。

全程不需要打开 BetterGI 界面，也不用改 BGI 里的任何推送设置。

二、两个版本怎么选
------------------------------------------------
两个版本都是「绿色软件」：不用安装、不写注册表、不建服务，
解压后双击 exe 就能用，删掉文件夹就是卸载。

唯一的区别是「运行时」放在哪。下载时按压缩包名区分：

  Dragon-Butler-v1.5.1-win-x64-runtime-dependent.zip   ← 需 .NET 8 运行时版
  Dragon-Butler-v1.5.1-win-x64-portable.zip            ← 免安装便携版

（名字规则：Dragon-Butler-v版本-平台-变体）

· 需 .NET 8 运行时版（exe 约 0.56 MB）
  运行时不在包里，要用电脑上已装的「.NET 8 桌面运行时」
  （Windows Desktop Runtime 8.0 x64，微软免费，装一次即可）。
  - 已经装了 → 双击就能跑，和便携版没有任何区别；
  - 没装 → 双击会弹出「需要 .NET」的提示并给下载地址，装完再双击即可。

· 免安装便携版（单文件约 155 MB）
  运行时已经打包进 exe 里，任何 Windows 10/11 x64 双击就能跑，
  不需要提前装任何东西。放 U 盘、换电脑、重装系统都能直接用。

两个版本功能完全一样，只是「要不要先补一个运行时」的差别。

三、第一次使用
------------------------------------------------
1. 双击 Dragon Butler.exe。
   程序需要读取游戏进程和结束 BGI 进程，因此会申请管理员权限（UAC 点「是」）。

2. 展开「工具」卡，给要用的工具指路：
   · 点【浏览】选中 exe（例如 D:\BetterGI\BetterGI.exe，要选到 exe 文件本身）；
   · 或点【自动寻找】让它自己找，命中后点「使用此路径」才生效；
   · 点【测试启动】可以单独试一下这个工具能不能起来。

3. BetterGI 卡里再选要跑的内容：
   · 只填「一条龙配置名」→ 跑该配置的一条龙；
   · 在「执行配置组」里勾选若干个组 → 按勾选顺序依次执行（1、2、3 就是顺序）；
   · 两者都填时，以勾选的配置组为准。

4. 回到上面的「睡前队列」卡，勾上今晚要跑的工具（可拖动排序），
   点【一键开跑】。运行时按钮变红「停止」，再点一次就是停下整个队列
   （先优雅关闭，兜底再强制结束）。只想单独跑一个，用工具卡里的【测试启动】。

四、几个常用的功能
------------------------------------------------
· 定时自动跑：打开定时卡开关，点时间可改成任意时刻，支持「每周几」重复。
  到点自动启动一条龙，电脑不在身边也能照常跑。

· 守护模式：默认开启。5 秒一次心跳，盯着进程、内存、画面冻结、任务进度。
  BGI 意外消失且一条龙还在进行中时，会在 60 秒冷却后自动重启。

· 挂机护航：队列跑起来后自动按住系统——不空闲睡眠、不因更新弹重启、不弹屏保，
  跑完自动把原设置还回去。不需要配置，也不改动你的电源计划。

· 夜间息屏：高级设置里可设「运行 N 分钟后关闭显示器」（默认关）。
  只是关屏，系统仍然保持唤醒，队列照常在后台跑。

· 疑似挂起：进程还活着，但 CPU 和日志连续 3 分钟都没动静，会在队列里标成「疑似挂起」
  并暂停队列、发通知等你处理；勾上「自动终止疑似挂起」则会结束进程并继续下一项。

· 自定义工具：工具卡最下方点「＋ 添加」，填程序路径、进程名、完成方式即可接入任意 exe。
  完成方式三种：
    「进程退出（退出码 0）」适合跑完自己退出的；
    「到达时长」适合不会退出的，跑满 N 分钟算完成并自动结束进程；
    「自定义信号」填日志文本 / 等待文件 / 窗口标题，任意一个命中就算完成（至少填一项）。
  图标会自动从 exe 里取，取不到就用首字母；任何工具都能点「换图标」换成自己的图，可随时还原。

· 按日计划：队列卡右上角「按日计划」打开 7 天 × 各工具的勾选表，
  可以给不同工具分配不同的星期（例如周本放周末）。它只影响定时触发：
  手动点「一键开跑」永远跑当前勾选；某天一个都没勾，到点会跳过并发一条提醒。
  队列里每个工具后面会显示「每天 / 6天」，队列下方写着今天跑哪几项。

· 晨报（默认关）：高级设置里打开后，每天第一次启动时用一句话汇报昨天的情况，
  例如「昨日队列：2 次运行，全部成功，总耗时 3小时12分」。昨天没跑就不播。

· 消息通知：「通知」卡片可选系统通知 / 企业微信 / 飞书 / 钉钉 / Telegram /
  Bark / 邮件 / Webhook 等渠道，跑完或出问题推到手机。

· 主题与音效：右上角可切「深色 / 浅色 / 跟随系统 / 自定义」。
  自定义主题支持调色板取色或选一张图片当背景，可调遮罩强度，左侧实时预览；
  「恢复默认主题」一键还原。按键音效默认关闭（静音），想听声音到「系统」卡打开。

五、文件都在哪
------------------------------------------------
所有数据都放在 exe 旁边，不写注册表、不写 %APPDATA%：

  config\settings.json   你的全部设置（删掉即恢复默认）
  config\group_archive.json  配置组当天的执行记录
  tools\                 每个工具一份档案（内置三个 + 你自己加的），删掉即恢复内置默认
  cache\icons\           从 exe 里提出的图标缓存，删掉会自动重建
  sounds\                程序自动生成的按键音效
  全部日志\              运行日志，出问题先看这里

整个文件夹可以直接拷走，换台电脑接着用。

六、常见问题
------------------------------------------------
Q：提示「找不到 BetterGI」？
A：路径要选到 BetterGI.exe 本身，不是它所在的文件夹。

Q：启动后没反应 / 秒退？
A：先看「全部日志」里当天的日志；「需 .NET 8 运行时」版请确认已装好 .NET 8 桌面运行时。

Q：托盘里还有图标，再双击 exe 提示「已在运行」？
A：程序是单实例的，从右下角托盘图标右键可以唤出主界面或退出。

Q：会误杀游戏或别的 BGI 吗？
A：所有进程操作都按「当前 Windows 会话」过滤，不会动别的用户会话里的进程。

Q：队列停在一项不动，卡片上写着「疑似挂起」？
A：说明进程还活着但 3 分钟内既没吃 CPU 也没写日志。看一眼游戏画面是否卡住，
   处理完点「继续」；不想每次都手动，可以在高级设置里打开「自动终止疑似挂起」。

Q：跑着跑着显示器黑了 / 电脑睡了？
A：只有「夜间息屏」会关显示器，那是正常的（系统仍在跑，动一下鼠标就亮）。
   其他情况不该发生——挂机护航会顶住空闲睡眠，跑完自动还回原设置；
   若确实睡了，到「全部日志」搜「护航」看有没有被别的程序抢回去。

Q：能加自己的工具吗？
A：能。工具卡最下方「＋ 添加」，填路径、进程名、完成方式即可，图标会自动提取。
   完成方式里最灵活的是「自定义信号」：日志文本 / 等待文件 / 窗口标题，填一项就行。

Q：按日计划设了，为什么手动开跑还是全跑？
A：按日计划只约束定时触发，手动「一键开跑」永远按当前勾选跑，方便临时补跑。
   想知道今天跑哪几项，看队列卡下方那行「今天（周五）跑 2 项」。

Q：晨报怎么开，为什么没播？
A：高级设置里打开「晨报」（默认关）。它每天只在第一次启动时播一句，
   昨天没有任何运行记录时不播；改完设置重启一次即可生效。

Q：怎么卸载？
A：退出程序后直接删掉整个文件夹即可（若开过开机自启，先在设置里关掉）。
